# 双账号学习平台方案说明

## 概述
为两人共用设计：你准备广东春季高考（春考），她准备大学考试+英语四六级+雅思托福。

## 架构设计

### 1. 账号分离
- **账号A（春考模式）**：语文、数学、英语
  - examMode: 'spring'
  - 目标分数: 450分
  - 考试日期: 2027年1月
  
- **账号B（本科模式）**：大学英语、法律、大学课程、论文
  - examMode: 'undergraduate'
  - 备考目标: CET-4/6、雅思、托福、法考、期末考试

### 2. 数据隔离
- 所有数据通过 userId 关联，天然隔离
- 练习记录、错题本、掌握度、背诵记录各自独立
- 共用同一套题目库，按科目筛选

### 3. 科目配置

#### 春考模式（现有）
| 科目 | 代码 | 题数 | 说明 |
|---|---|---|---|
| 语文 | Y | 75 | 已修复17道题型错误 |
| 数学 | M | 67 | 全部正确 |
| 英语 | E | 119 | 已修复1道答案错误 |

#### 本科模式（新增）
| 科目 | 代码 | 题数 | 说明 |
|---|---|---|---|
| 大学英语四级 | CET4 | ~50 | 听力+阅读+完形+翻译+写作 |
| 大学英语六级 | CET6 | ~30 | 难度高于四级 |
| 雅思 IELTS | IELTS | ~20 | 写作+阅读样本 |
| 托福 TOEFL | TOEFL | ~20 | 阅读+听力样本 |
| 法律基础 | LAW | ~40 | 宪法+民法+刑法 |
| 大学通识课 | UNIV | ~30 | 高数+语文+思修 |
| 论文写作 | PAPER | 4 | 选题+结构+引用+查重 |

## 使用方式

### 方式一：切换账号（推荐）
1. 各自登录自己的账号
2. Dashboard 自动显示对应科目卡片
3. 练习/模考/错题本完全独立

### 方式二：同设备共用
1. 使用"我的"页面切换考试模式
2. 临时切换查看对方进度
3. 数据仍然隔离

## 文件修改清单

### 后端
- `backend/prisma/schema.prisma` — 新增 examMode, examTargets 字段
- `backend/seed/seed-undergraduate.json` — 本科模式种子数据
- `backend/prisma/seed-undergraduate.js` — 导入脚本
- `backend/scripts/generateUndergraduateQuestions.mjs` — AI批量生成脚本

### 前端
- `frontend/src/types/index.ts` — User 类型更新
- `frontend/src/pages/Dashboard.tsx` — 按模式显示不同科目
- `frontend/src/pages/Profile.tsx` — 添加模式切换
- `frontend/src/components/Layout.tsx` — 根据模式显示不同导航

## 部署步骤

```bash
# 1. 更新数据库 Schema
cd 2027spring-exam/backend
npx prisma migrate dev --name add-exam-mode

# 2. 导入本科模式种子数据
npm run seed:undergraduate

# 3. （可选）AI批量生成更多题目
npm run generate:undergraduate

# 4. 构建前端
cd ../frontend
npm run build
```
